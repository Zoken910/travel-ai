# Week 44 — Prerequisites and repo scaffold (Phases 0–1)

## Done

- Installed Git, GitHub CLI, uv and Ollama; pulled `qwen3:8b` and `nomic-embed-text`.
- Created the public `travel-ai` repo with an MIT license.
- Set up the uv project with core and dev dependencies, Ruff and pre-commit.
- Created the folder layout and documentation skeleton: README, setup guide, ADR 0001,
  issue/PR templates, changelog.

## Problems and how I solved them

- Ran `uv init` in the parent folder instead of inside the cloned repo; moved `pyproject.toml`,
  `uv.lock` and friends into the repo.
- `uv init` created a `src/travel_ai` package, but the planned layout uses top-level folders
  (`orchestrator/`, `db/`, ...). Switched the project to `package = false` and added the repo root
  to pytest's `pythonpath`.

## Learned

- Git doesn't track empty folders, so the scaffold uses `.gitkeep` files.
